# Scalar assessment requirements

The capitalized key word MUST follows [BCP 14](https://www.rfc-editor.org/info/bcp14).

<a id="qual-req-008"></a>
## QUAL-REQ-008 Exact request

An assessment MUST refuse a mismatched expected policy, registry, use, subject, implementation or claim binding.

<a id="qual-req-009"></a>
## QUAL-REQ-009 Selected reports

A report MUST contribute only if its exact digest and scope match a caller selection.

<a id="qual-req-010"></a>
## QUAL-REQ-010 Observations and execution

The sceptical result MUST distinguish accepted support, opposition, both, neither and explicit non-execution.

<a id="qual-req-011"></a>
## QUAL-REQ-011 Decimal controls

A control MUST compare exact values in the reported unit at the inclusive tolerance boundary.

<a id="qual-req-012"></a>
## QUAL-REQ-012 Dependence

Contested dependence MUST remain unresolved even under a requirement for any known relation.

<a id="qual-req-013"></a>
## QUAL-REQ-013 Run status

An interrupted or failed run MUST oppose a run completion prerequisite.

<a id="qual-req-014"></a>
## QUAL-REQ-014 Selection

A selection rule MUST preserve its fixed obligation set and report contested items separately from definite omissions.

<a id="qual-req-015"></a>
## QUAL-REQ-015 Raw bodies

A body finding MUST compare both the digest and size of supplied bytes to the accepted observation.

<a id="qual-req-016"></a>
## QUAL-REQ-016 Initial temporal boundary

An unimplemented temporal premise MUST leave exact compatibility unresolved and cannot support a positive qualification.

<a id="qual-req-017"></a>
## QUAL-REQ-017 Recomputed verification

The receiver MUST compare the full result with a recomputation from the bound raw request.
